## `display` 不只是“换不换行”

HTML 元素有常见的默认 display 行为，但 CSS 可以改变它们生成的 box 如何参与布局。只把 `block` 记成“会换行”、把 `inline` 记成“不会换行”，不足以解释很多 sizing 和布局行为。

<Concept title="分开看 outer participation 与 inner formatting">
`display` 可以用两个层面理解：

- **outer display type**：这个 box 怎样参与周围的 flow。
- **inner display type**：这个 box 的 children 怎样布局。

在本课范围内：

- `block` 生成 block-level participation 的 box，内部仍是普通 flow。
- `inline` 生成 inline-level participation 的 box，跟文字和其他 inline-level content 一起参与 inline formatting。
- `inline-block` 可以理解为 `inline flow-root`：outer 仍是 inline-level，但内部形成独立的 flow-root，并具备更适合明确 sizing 的 box 行为。
- `none` 让该元素及其 descendants 不生成 box。

Flex/Grid 会改变 inner layout，但会在后续 Module 单独学习。
</Concept>

`display: none` 也不是“透明”。透明元素仍可能生成 box；`display: none` 的关键区别是该元素不生成 box。这个选择还有 accessibility 边界：`display: none` 通常也会让该元素及其 descendants 从 accessibility tree 中消失，所以它适合“当前内容对所有用户都不应出现”的场景，不适合“只在视觉上隐藏、但仍要让辅助技术读取”的内容。后者需要专门的 visually-hidden strategy，而不是把 `display: none` 当成通用隐藏工具。
