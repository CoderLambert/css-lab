## 一个元素不是一条 `width`

浏览器进行布局时，元素会生成 box。讨论“这个元素有多宽”之前，先要说清楚你指的是哪一条 box edge。

<Concept title="从 content 向外读 box model">
标准 box model 可以按从内到外的顺序理解：

`content → padding → border → margin`

`padding` 在内容和边框之间；`border` 包住 content 与 padding；`margin` 位于 border 外部，用来参与 box 与周围 box 的间距关系。

`box-sizing` 决定 authored `width` / `height` 如何映射到这些边界：

- `content-box`：指定尺寸作用于 content box；padding 和 border 会继续增加 border box 的尺寸。
- `border-box`：指定尺寸作用于 border box；padding 和 border 从指定尺寸内部占用空间。
- margin 在两种模式下都不属于 `width` / `height` 指定的 box。
</Concept>

<Predict
  question="一个元素使用 content-box，width: 200px，左右 padding 各 20px，左右 border 各 5px。它的 border box 宽度是多少？"
  options={["200px", "240px", "250px"]}
  answer="250px"
  explanation="content-box 下 200px 只描述 content box。左右 padding 共 40px、左右 border 共 10px，所以 border box 为 250px。"
/>

  leftCode="box-sizing: content-box; width: 200px;"

`border-box` 往往让组件尺寸更容易推理，但它不会让所有 sizing 问题消失。内容本身、min/max constraints、containing context 和 overflow 仍会继续影响最终布局；这些会在本 Module 后面的 Lesson 继续处理。
