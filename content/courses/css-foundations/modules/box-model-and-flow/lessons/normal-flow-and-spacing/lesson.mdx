## 没有声明 layout 也有 normal flow

<Concept title="normal flow 是默认的 layout algorithm">
如果没有应用 Flexbox、Grid、positioning 或 float 等会改变参与方式的 CSS，元素不会“悬空”等待坐标。浏览器会让 block-level box 沿 block direction 依次排布，让 inline-level content 在 line box 中排布并在需要时换行。

`margin` 是 box 外部的 spacing；`padding` 则属于 box 内部。对普通 block flow 来说，水平 `auto` margin 可以把剩余 inline space 分配到两侧；这是一种空间分配规则，不是把元素移动到一个绝对 x 坐标。

相邻 block 的垂直 margin 在特定条件下会 collapse。两个正 margin 接触时，简单情形的结果是较大的那个，而不是机械相加。父子 block 的边缘 margin、空 block 的上下 margin 也可能形成同一个 collapsing set；border、padding、内容、明确的高度或新的 formatting context 等会打断某些 collapse。它不是随机 bug，也只涉及 block-axis 的 margin。
</Concept>
