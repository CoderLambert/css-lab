## Grid 先建立二维 track system

Flexbox 先沿一条轴处理项目；Grid 则先建立水平与垂直两组 tracks，再把 items 放进这些 tracks 形成的 areas。不要把 Grid 记成“二维 Flexbox”：它们可以组合，但 mental model 的起点不同。

<Concept title="track、line 与 explicit grid">
`display: grid` 建立 grid formatting context。`grid-template-columns` 和 `grid-template-rows` 定义 explicit grid 的 tracks。track 是两条相邻 grid lines 之间的空间；line 是 track 的边界。因此定义两条 column tracks 会得到三条 vertical grid lines，line number 不是 track number。

固定 track（例如 `160px`）直接给出一个 sizing function；`fr` 是 flexible fraction，用于在固定/内容所需空间和 gutters 之后分配剩余空间。`1fr 2fr` 表达剩余空间的比例，不是两个永远等于 33%/67% 的百分比，也可能受到内容、最小尺寸和可用空间影响。

本课把 track definition 作为作者输入来检查。`rule-style` 读取 learner stylesheet 中匹配规则的 authored declaration，因此可以区分 `160px 1fr` 与 `1fr 1fr`；它仍不等于完整的 track sizing、内容溢出或最终几何证明，这些结果需要结合 Preview 观察。
</Concept>
