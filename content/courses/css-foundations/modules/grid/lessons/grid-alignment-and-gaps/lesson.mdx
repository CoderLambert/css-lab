## Grid alignment 也要先问作用层级

Grid 与 Flexbox 共享 Box Alignment 的许多 property 名称，但 alignment 的对象不同。先判断是在 grid area 内对齐 item、在 container 中分布整个 grid content，还是在 tracks/items 之间放置 gutter。

<Concept title="item alignment、content alignment 与 gap">
`align-items` / `justify-items` 控制 grid items 在各自 grid areas 中的默认对齐；`align-self` / `justify-self` 可以为单个 item 覆盖它。`align-content` / `justify-content` 则在 tracks 没有填满 container 时分布整个 grid content。

`gap` 为相邻 rows/columns 之间建立固定 gutter。它不是 item alignment，也不是把剩余空间按 `space-between` 分配；它可以和 content alignment 同时存在。Grid 与 Flexbox 不是两套完全无关的 alignment 体系，但需要把 property 的作用对象读清楚。
</Concept>
