## 用 lines 表达 item 占据的 area

Grid item 的位置不是一对任意的 x/y 坐标。作者告诉 Grid：这个 item 从哪条 line 开始、到哪条 line 结束，或从起点开始跨过几条 tracks；placement algorithm 再把这个区域与 grid tracks 对上。

<Concept title="start/end line 与 span">
`grid-column-start` / `grid-column-end` 描述 column lines，`grid-row-start` / `grid-row-end` 描述 row lines。start line 包含 item 的起边界，end line 是结束边界；例如从 column line 1 到 line 3 覆盖两条 column tracks，而不是三条。

`span 2` 不是 line number，它表示从已知的起点跨越两条 tracks。line number 也不是 track number：两条 tracks 有三条 lines，line 3 是第二条 track 的 end edge。

显式 placement 改变的是 item 在 grid area 中的位置，不会改写 HTML 的 DOM/source order。视觉位置和 source order 需要分别推理。
</Concept>
