## 未指定项目也会进入一个算法

Explicit grid 是由 `grid-template-columns` / `grid-template-rows` 明确声明的 tracks；但不是每个 item 都必须手写 placement。没有被显式放置的 items 会进入 Grid 的 auto-placement algorithm，浏览器按既定 flow direction 寻找可用位置。

<Concept title="auto-placement 会扩展 implicit grid">
当 auto-placement 需要的空间超出 explicit grid 时，Grid 可以创建 implicit tracks。它不是“随机自动布局”：auto-flow direction、已有 placement、dense 选项以及 `grid-auto-rows` / `grid-auto-columns` 等都参与这个过程。

`grid-auto-flow: row` 与 `column` 改变算法优先填充的方向；`grid-auto-rows` 和 `grid-auto-columns` 为自动生成的 tracks 提供 sizing rule。不要把 implicit track 当成作者已经在 template 中写出的 explicit track，也不要从一次静态 declaration check 推断最终 item geometry 或 visual order。
</Concept>
