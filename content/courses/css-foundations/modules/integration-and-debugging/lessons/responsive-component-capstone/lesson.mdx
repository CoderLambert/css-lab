## 综合练习的边界先于具体 property

Capstone 的 HTML 是固定 fixture；你只编辑 CSS。base.css 已经提供 surface、基础 typography 与局部边框/padding scaffolding，本题不会把这些固定作者样式冒充成 learner 练习。你真正要综合的是：外层 constraint、Flex header/actions、指定的 Grid body、长内容带来的 intrinsic/overflow pressure、selective responsive adaptation，以及最后的 debugging pass。

<Concept title="固定 HTML，分阶段建立可解释的 CSS system">
先把问题拆成几个能回看的阶段：

1. provided scaffolding：先识别 base.css 已经固定的 surface / typography，不重复把它们算成自己的实现成果。
2. box / constraints：用 `max-width` 让外层 dashboard 不超过 available space，并检查长 token 是否制造 intrinsic/overflow pressure。
3. internal layout：本 capstone 明确练习 Flex header/actions + Grid body；先建立 formatting context，再谈 tracks 与 alignment。
4. content-pressure diagnosis：让 feature 中的长 build token 在窄空间可安全换行，区分 layout context 与内容本身的 overflow 原因。
5. responsive adaptation：先让窄空间 baseline 成立，再在给定宽空间条件中为 Grid body 增加两列 tracks。
6. debugging pass：若结果不对，沿 selector → cascade → defaulting → value → context → constraint → environment pipeline 回查，而不是继续堆叠规则。

HTML 不可编辑是边界的一部分：它迫使你用已经存在的 DOM 关系解释布局，同时避免 capstone 变成另一个 HTML editor 或 generic IDE。
</Concept>
