## 没有 winning declaration，不等于“没有值”

Cascade 先决定元素自身有没有 winning declaration。只有某个 property 没有得到 cascaded value 时，CSS 才进入 defaulting：这个 property 要么从 parent 继承，要么使用它自己的 initial value。

<Concept title="Inheritance 是 defaulting 的一部分，不是 selector matching">
CSS properties 分成默认继承与默认不继承两类。

- inherited property 在元素没有 cascaded value 时，通常使用 parent 的 computed value；
- non-inherited property 在没有 cascaded value 时，使用该 property 定义的 initial value。

因此 child 没有写 declaration，仍然会得到一个 value。继承也不是“parent selector 自动匹配 child”。
</Concept>

## Inherited 与 non-inherited property 走不同 defaulting 路径

<Compare
  leftTitle="inherited property"
  leftCode="font-weight"

  rightTitle="non-inherited property"
  rightCode="border-style"
  rightMeaning="没有 cascaded value 时，不自动复制 parent；会走自己的 initial value。"
/>

property 的 **initial value** 是 CSS 对该 property 定义的初始值，不要把它和浏览器 user-agent stylesheet 中的默认规则混为一谈。

如果 child 自己存在 winning declaration，那么该 declaration 会先决定结果；只有缺少 cascaded value 时，继承/defaulting 才补上 value。
