## 同一个数字，reference context 可能完全不同

CSS declaration 里的 value 不是总能脱离 property 和上下文单独解释。`px` 是 absolute length；`em`、`rem`、percentage 等 relative value 必须先知道自己的 reference context，才能理解最终结果。

<Concept title="Authored value 不等于最终观察到的 value">
浏览器会经历 specified、computed、used 等 value processing 阶段。相对单位和 percentage 可能在不同阶段结合上下文被解析；`getComputedStyle()` 暴露的是 resolved value，而不是保证原样返回你写进 stylesheet 的 source spelling。

因此 checker 看到 `32px`，不能反推 learner 一定写了 `32px`；它也可能来自 `2rem`、`calc()` 或其他等价表达。
</Concept>

## relative unit 的 reference 由 unit 和 property 共同决定

<Compare
  leftTitle="em"
  leftCode="font-size: 1.5em"
  leftMeaning="用于 font-size 时相对 parent 的 font-size；em 在其他 property 上的计算上下文也与当前元素 font-size 相关。"
  rightTitle="rem"
  rightCode="font-size: 1.5rem"
  rightMeaning="相对 root element 的 font-size，不是相对直接 parent。"
/>

Percentage 更不能统一解释成“viewport 的百分比”。它的 reference 由具体 property 定义；例如本课只在明确尺寸上下文中观察 width percentage。

`calc()` 可以组合兼容的 value，例如 `calc(100% - 24px)`。它不是把 CSS 变成任意数学语言；表达式仍必须产生该 property 接受的 value type。
