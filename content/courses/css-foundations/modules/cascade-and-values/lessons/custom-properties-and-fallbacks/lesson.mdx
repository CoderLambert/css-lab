## Custom property 不是全局常量

以 `--name` 声明的普通 custom property 仍然是 CSS property：它声明在元素上，参与 cascade，并且默认继承。`var()` 则在另一个 property 的 value 中引用它。

<Concept title="先决定 custom property 的 value，再在使用点 substitution">
`--accent: ...` 的 declaration 会像其他 property 一样参与 cascade。对于未用 `@property` 注册的 custom property，child 默认可以继承 parent 的 value。`color: var(--accent)` 在使用点把当前元素得到的 `--accent` value substitution 进去。

因此 nested override 不是修改某个 JavaScript/global constant；它是在更具体的元素上下文中得到另一个 cascaded custom-property value。
</Concept>

## Fallback 只在引用值不可用时介入

<Compare
  leftTitle="已有 usable value"
  leftCode="var(--space, 12px)"
  leftMeaning="如果 --space 对当前元素有 usable value，就使用它；fallback 不参与。"
  rightTitle="没有 usable value"
  rightCode="var(--missing, 12px)"
  rightMeaning="引用的 custom property 没有 usable value 时，第二个参数作为 substitution fallback。"
/>

Fallback 不是“不支持 CSS variables 时的兼容方案”，也不是永远会执行的默认值。它只解决 `var()` 引用值不可用等 substitution 场景。

本 Foundations lesson 不引入 `@property` 注册语义；这里讨论的是普通 `--*` custom properties。
