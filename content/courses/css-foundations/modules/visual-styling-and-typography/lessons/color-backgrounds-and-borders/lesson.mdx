## 颜色、背景与边框是不同的绘制层

一个 box 已经参与 layout 之后，才有“它怎样被画出来”的问题。不要把所有视觉变化都叫作 layout：文字前景、背景和边框各自对应不同的 paint layer，也分别有自己的 CSS property。

<Concept title="把 paint layer 与 box edge 分开看">
`color` 描述文字等前景内容使用的颜色；`background-color` 在 box 背后绘制背景；`border-color` 与 `border-style` / `border-width` 描述 box 边缘的边框。背景会绘制在边框后面，内容绘制在背景与边框的上方。

背景颜色改变的是绘制，不会自动给 box 增加一层 padding。边框则仍然是 box model 的一部分：在默认 `content-box` 下，边框会增加 border box 的外部尺寸；`border-box` 会把它纳入 authored size 的内部计算。`border-radius` 改变边角的绘制形状，但不等于改变布局模式。
</Concept>
