## 文字样式也是布局输入

文字不只是 box 里面一串不会影响外部的像素。字体、字号、字重与行高共同影响 glyph 和 line box；可用的 inline measure 决定文字在哪里换行，因此 typography 既是视觉样式，也是 layout input。

<Concept title="从继承、line metrics 与可用宽度推理文本">
`font-family` 选择字体族和 fallback，`font-size` 影响 glyph 的尺度，`font-weight` 影响字重；`line-height` 为一行文字提供 line box 的高度。`line-height` 可以大于 `font-size`，它不需要机械地等于字号。

许多文字属性会继承。把类型设置在 `.profile` 上，里面的 heading、paragraph 等后代通常会拿到继承值；需要例外时，再在更具体的后代上覆盖。继承不是“所有 CSS property 都向下复制”，要分别知道 property 的语义。

文本是否换行还取决于包含它的 box 有多少 inline space、空白与断行机会，以及连续 token 是否允许断开。固定 `height` 只是限制 box，不是一个可靠的排版策略；先让 line metrics 与可用宽度正确，再观察内容如何流动。
</Concept>
