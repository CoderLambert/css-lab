## 先找到对象，再讨论样式

一条 CSS 规则不是“把样式写进 HTML”。浏览器会先判断 selector 匹配哪些元素，再把规则里的 declarations 作为这些元素的样式候选。

<Concept title="CSS 规则的最小 mental model">
可以把普通 style rule 拆成两步：

1. selector 决定“哪些元素进入这条规则的匹配集合”；
2. declaration block 中的 property/value 对，只对这些匹配到的元素提供样式候选。

所以“selector 没匹配到”和“property/value 写错”是两类不同问题。
</Concept>

下面这条规则中，`.notice` 是 selector，`font-weight: 700` 是 declaration；其中 `font-weight` 是 property，`700` 是 value。
