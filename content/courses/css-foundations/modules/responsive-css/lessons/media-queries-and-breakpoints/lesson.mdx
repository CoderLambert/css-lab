## media query 是 conditional rule selection

Media query 不会创造一个“手机模式”。它根据当前 environment condition 选择是否让某组 CSS rules 参与 cascade；命中之后，selector、specificity、source order 与其他 declarations 仍然决定最终 winner。

<Concept title="breakpoint 来自内容/布局断裂">
`min-width` 表达“当 available viewport width 至少达到某个条件时选择这组规则”，`max-width` 表达相反方向。数字应该来自 nav 是否放得下、cards 是否需要换行、文字 measure 是否失控等 content/layout need，而不是来自 iPhone、iPad、desktop 这样的设备品牌表。

Mobile-first 是一种 source-order 策略：先写较窄空间也成立的 baseline，再用较宽条件的 query 增加或改变必要规则。它不等于把 390px 当作永远正确的 breakpoint，也不意味着 query 命中后 cascade 就停止。
</Concept>
