## responsive 先从 constraints 开始

Responsive behavior 不等于先列出几个设备宽度。元素能否适应 available space，通常先由 intrinsic content、preferred size、min/max constraints 以及 Flexbox/Grid 的 flexible tracks/items 共同决定。

<Concept title="available space + intrinsic constraints + flexible layout">
`width: 100%`、百分比、`max-width`、`min-width` 等声明把组件放回 containing context 的可用空间中；它们仍然要和内容的 intrinsic size、box model 和 overflow 一起推理。一个固定的 `320px` 并不自动错误，但如果它超过可用空间，就需要约束或另一种布局策略。

Flexbox 的 wrap、Grid 的 flexible tracks、`minmax()` 或一个合理的 max constraint 都可能让同一份 CSS 在不同 available space 下自然变化。Media query 是在某个真实 layout/content break 出现时选择另一组规则，不是 responsive 的唯一来源。
</Concept>
