## item-level control 不会重写整个 container 算法

Flex container 已经决定了 main/cross axis 和基本的 line layout；item-level properties 只在这个模型上做局部调整。先区分“覆盖某个 item 的 cross-axis 对齐”“把剩余空间推到某个 margin”“改变视觉顺序”这三种问题。

<Concept title="align-self、auto margin 与 order 的边界">
`align-self` 可以覆盖单个 item 的 `align-items` 默认值，但它仍然沿同一条 cross axis 工作。它不是另一套坐标系统。

Flex context 中的 auto margin 会吸收对应 axis 上的剩余空间，因此 `margin-inline-start: auto` 常用来把一组 actions 推向 main-axis 末端。它描述的是空间分配，不是一个固定像素位置。

`order` 影响 flex items 的视觉排列顺序，但不会重写 DOM/source order，也不会自动重排键盘焦点、屏幕阅读器阅读顺序或其他 accessibility 顺序。视觉顺序与交互顺序不一致时应当谨慎使用。
</Concept>
