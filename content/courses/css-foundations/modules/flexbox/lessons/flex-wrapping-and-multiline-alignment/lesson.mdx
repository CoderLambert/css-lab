## wrap 创建 lines，alignment 有不同层级

当一行 flex container 放不下所有 items 时，`flex-wrap: wrap` 允许 Flexbox 把 items 分成多条 flex lines。每条 line 仍然沿 main axis 排列 items；新增的 line 不是把 Flexbox 变成 Grid，而是同一个一维算法产生了多个 line。

<Concept title="item alignment 与 line alignment 不是一层">
`align-items` 处理每条 flex line 内，items 沿 cross axis 的默认对齐；`align-content` 处理多条 lines 作为整体在 container cross axis 中如何分布。单行 flex container 没有多条 line 可分布，`align-content` 通常不会产生你期待的多行效果。

`gap` 是相邻 items/lines 之间的 gutter；它不是 `justify-content`。`justify-content` 仍然沿每条 line 的 main axis 分配剩余空间。读 property 前先确认它作用在 item、line 还是 gutter。
</Concept>
