## 先读轴，再选择 alignment property

上一课已经建立 flex formatting context、flex items 与 main/cross axis。本课只聚焦：这些轴确定以后，两个常用 alignment property 如何分工，以及它们怎样消费容器里的剩余空间。

<Concept title="justify-content 与 align-items 的职责">
`justify-content` 沿 main axis 分布 flex items；`align-items` 沿 cross axis 处理项目的默认对齐。轴由 `flex-direction` 决定，所以属性名不能直接翻译成“水平”和“垂直”。

例如 `column` 把 main axis 放到 block direction，视觉水平方向就落在 cross axis；此时水平居中仍然要看 `align-items`。`align-items: flex-end` 与 `align-items: end` 在这个练习的普通书写模式中都表达 cross-axis end，但前者是 Flexbox 传统值，后者来自更通用的 Box Alignment 语义。
</Concept>
