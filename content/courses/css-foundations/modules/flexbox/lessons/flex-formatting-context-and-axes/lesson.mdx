## `display: flex` 先建立一种新的上下文

Flexbox 不是一个“水平居中按钮”。它先改变容器的 formatting context，再让后续的 sizing、alignment 和 free-space 算法有一个明确的工作空间。

<Concept title="从 formatting context 读出两条轴">
当容器使用 `display: flex` 时，它建立 flex formatting context；它的 direct children 成为 flex items。后代更深层的元素不会因为祖先是 flex container 就自动变成同一层的 flex item。

`flex-direction` 定义 main axis：`row` 沿 inline direction 排列，`column` 沿 block direction 排列（在常见的水平书写模式中，分别看起来像横向和纵向）。cross axis 永远与 main axis 垂直。之后的 `justify-content` 处理 main axis，`align-items` 处理 cross axis；不要把它们背成固定的水平/垂直属性。
</Concept>
