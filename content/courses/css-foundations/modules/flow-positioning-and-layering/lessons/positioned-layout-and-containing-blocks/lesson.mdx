## 先区分 flow participation 与 reference context

`position` 不是给元素套上一个“坐标模式”的总开关。它同时回答两个问题：box 是否继续以原来的方式参与 normal flow，以及 offset 应该参照哪个 containing block 计算。

<Concept title="relative 保留位置，absolute 改变参与方式">
`static` 是普通定位值，元素按当前 formatting context 参与 normal flow。`relative` 先完成 normal-flow 布局，再根据 `top`、`left` 或 `inset` 做视觉偏移；原来的 flow slot 仍然保留，所以后续内容不会把它当成消失了。

`absolute` 则从 normal flow 中移出。它的 offset 通常相对最近的、能建立 containing block 的祖先，而不是永远相对 viewport。让一个祖先使用 `position: relative` 是常见的显式锚点；这不会让祖先自身离开 normal flow。

`top` / `left` 是相对 containing block 的 positioned offset，不等于 `transform: translate(...)`。两者都可能改变屏幕上的位置，但参与布局的时机与影响不同。先找到 flow participation 和 containing block，再读 inset 值，通常比直接猜坐标可靠。
</Concept>
