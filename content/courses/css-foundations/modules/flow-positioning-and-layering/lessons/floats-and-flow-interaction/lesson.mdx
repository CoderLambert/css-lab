## float 改变 box placement，也改变文字可用的 line box

`float` 是一种特定的 flow interaction mechanism：box 会向左或右移动，后续 inline content 的 line boxes 会避开它并在旁边环绕。它不是任意坐标定位，也不是现代整页布局的默认替代方案。

<Concept title="float 与 clear 的短模型">
浮动 box 不再按普通 block flow 的位置占据布局，但它仍会影响周围内容的排布；inline content 可以围绕 float，形成适合图片加说明文字的窄场景。`clear` 则要求元素避开指定一侧的 float，直到可以在其下方开始。

因此看到文字环绕时，先问“哪一个 box 被 float 推到一侧，哪些 line boxes 为它让路”；看到标题落到图片下方时，再问是否需要 `clear`。这和 `position: absolute` 的 containing-block offset 不是同一套机制。

现代页面的主要区域通常使用 Flexbox、Grid 或正常约束布局；本课只保留 float/clear 的 flow interaction 与历史背景，不重建 legacy float-based full-page layout 或 clearfix 框架。
</Concept>
