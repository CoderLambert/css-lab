## 3. 最终 curriculum-quality audit rubric

最终 sign-off 不再只依赖 schema/build/E2E。课程审核必须同时检查：

1. **Factual CSS model**：cascade/defaulting/inheritance、logical/Flex axes、intrinsic sizing、Grid placement、positioning、float、responsive condition 等术语与机制正确。
2. **Fixture causal validity**：starter/base 必须真实实例化所声称的 CSS mechanism；不能由 border、固定宽度、预先完成的 scaffolding 等条件消除实验现象。
3. **Checker truthfulness**：checker evidence 必须对应 learning objective；authored semantics 用 `rule-style`，computed outcome 用 `style`/`viewport-style`，结构才用 `exists`/`count`。
4. **Bypass resistance**：检查 helper-class shortcut、hard-coded resolved pixels、删除 conflict、same-value declarations、`!important`、inert Grid declarations、无关 convenience selector 等路径。
5. **Equivalent-solution policy**：只有 objective 允许时才接受等价实现；`rule-style` 的 exact selector/media matching 不得被描述成任意语义等价证明。
6. **Experiment contrast**：starter 与 solved state 必须因目标 mechanism 产生可观察差异；不能比较行为等价状态。
7. **Prompt/hint leakage**：成熟 Lesson 的 first attempt 以 prediction/diagnosis/constraint 为主；exact syntax/value 留到后续 rescue hint，除非明确是 syntax warm-up。
8. **Progression**：相邻 Exercise 增加 retrieval、diagnosis、transfer 或 synthesis demand，避免立即重复同一 declaration。
9. **Capstone synthesis**：只把 learner 实际可编辑的决策计入综合目标；固定 `base.css` 必须明确标为 scaffolding。
10. **Accessibility/responsive caveats**：focus/focus-visible、`display:none` accessibility tree、source/visual order、breakpoint rationale 与 viewport sampling 的边界必须明确。

## 5. Checker capability boundary

当前 checker 可以诚实证明的内容：

- `style`：fixture 上的 computed/resolved style outcome。
- `rule-style`：CSSOM 中 bounded authored selector/property/value，以及可选 normalized media condition。
- `viewport-style`：受支持固定 viewport width 下的 computed style sample。
- `exists` / `count`：DOM selector existence / match count。

仍然不能据此宣称：

- selector list / media query 的任意语义等价；
- declaration priority（例如 `!important`）的完整证明；
- arbitrary continuous viewport geometry、line count、wrapping、paint/occlusion、scroll threshold；
- pointer/keyboard modality 本身；
- learner 的 reasoning process。

当这些行为是学习重点时，课程使用 Predict/Compare/Preview observation 明确承担不可机器证明的部分，而不是用 resolved pixel 或 authored token proxy 冒充完整 mastery。

## 6. Progression and capstone disposition

M1→M9 保持由 CSS language/selection、cascade/value、box/flow、visual/typography、Flex、Grid、positioning、responsive 到 integration/debugging 的依赖链。

最终 capstone 现在明确区分：

- **provided scaffolding**：surface、基础 typography、局部 border/padding；
- **learner decisions**：outer constraints、Flex header/actions、Grid body、long-content overflow handling、selective responsive adaptation、debugging pass。

checker 要求先建立 Grid formatting context，再验证 authored tracks/conditional rules；Preview 负责完整 geometry 与连续 viewport 的观察。固定作者 CSS 不再被计入 learner synthesis 成果。
