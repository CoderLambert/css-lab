# M6A — Workspace Domain / Front-end Lab Core 执行总计划

## 1. 执行基线

开始任务前必须：

1. 切到 `main`。
2. 拉取最新代码。
3. 阅读根目录 `AGENTS.md`。
4. 再读取本任务涉及的文件，不允许仅依据本文档猜测当前实现。
5. 如果 `main` 已经包含本文档所描述的部分改动，先审计差异，再只补缺失项。

本计划基于：

```text
repository: CoderLambert/css-lab
baseline main: 2f617c50aab2f31943d5745760f5ed354d026a92
```

M6A 的目标不是实现 JavaScript / TypeScript Runtime，而是把当前“一个 Exercise = 一个 CSS 字符串”重构为：

```text
Disk Content
→ Workspace Definition
→ Learner Draft
→ Execution Snapshot
→ Browser Runtime
→ Checker
→ Progress / Learning Shell
```

## 2. 必须遵守的架构结论

以下为已定设计，不在执行阶段重新发散：

- Course / Module / Lesson 保持 `schemaVersion: 1`。
- Exercise 单独升级为 `schemaVersion: 2`。
- Workspace language 使用闭合 union：`html | css | javascript | typescript`。
- Workspace path 是 POSIX 风格逻辑相对路径，不是操作系统文件路径。
- 允许 content author 定义子目录；learner 当前不能创建、删除、重命名文件。
- locked file 使用 `editable: false`，不要再增加 `locked` 字段。
- Browser entry 属于 Runtime Definition，不属于 Workspace Definition。
- `fixture.html` 概念删除。
- 当前内容迁移为 `starter/` + `solution/`。
- 不创建 `support/`；当前 `base.css` 迁移成 locked workspace file。
- `solution/` 只包含 editable file 的参考答案。
- Solution 不得进入 learner-facing `Exercise` runtime domain。
- Learner Draft 只保存 editable files。
- Progress 只保存 Learner Draft，不保存 locked files、solution、compiler output、console 或 runtime state。
- Execution Snapshot 是 runtime/checker 的完整、不可变输入。
- TypeScript 是未来 Toolchain，不是 Runtime。
- M6A 不加入假的 `toolchain: null` 或 toolchain placeholder。
- M6A 不设计 Worker Runtime DSL。
- Browser Runtime 仍使用 sandboxed iframe。
- 平台消息 source 使用 `lab-host` / `lab-runtime`。
- CSS 热更新继续使用具体消息 `css:update`。
- HTML 修改在 M6A 直接重建 Browser document，不提前加入 `html:update`。
- 不创建 UniversalEditor、LanguageRegistry、RuntimeRegistry、CheckerRegistry 等万能抽象。

## 3. 执行顺序

必须按以下顺序执行。除非前一阶段 acceptance criteria 已满足，否则不要进入下一阶段。

1. **Task 01 — Workspace Domain + Exercise Schema v2**
2. **Task 02 — Content Assets + ContentReader + Studio Content Health**
3. **Task 03 — Progress v2 + IndexedDB migration**
4. **Task 04 — Workspace Editor + HTML/CSS editing**
5. **Task 05 — Execution Snapshot + Browser Runtime boundary + protocol**
6. **Task 06 — Integration / security / regression / AGENTS**

每个任务建议独立 commit。不要把六个阶段压成一个巨大 commit。

## 4. 全局非目标

整个 M6A 期间禁止顺手实现：

- JavaScript execution
- TypeScript compiler
- Worker Runtime
- interaction checker
- Console
- npm
- Vite runtime
- WebContainer
- terminal
- arbitrary package installation
- React/Vue/Svelte Lab
- generic filesystem
- file create/delete/rename
- cloud sync
- auth
- global state library
- runtime/toolchain/plugin registry

## 5. 全局验证

每个阶段至少运行：

```bash
pnpm lint
pnpm build
```

涉及 learner runtime、Progress、Studio 后同时运行：

```bash
pnpm test:e2e
```

不要通过修改、跳过或删除现有测试来“通过验证”。如现有测试需要因明确的数据结构变化更新，应保留原测试意图并增加新覆盖。

## 6. 最终 Definition of Done

M6A 完成时必须满足：

- 当前 3 个 CSS Exercise 行为无回归。
- Exercise runtime domain 已不存在 `fixtureHtml` / `baseCss` / `starterCss`。
- Progress 已不存在 `code: string`。
- learner 可编辑 HTML + CSS。
- locked HTML/CSS 可以参与 execution，但不进入 Learner Draft。
- solution 永不进入 learner props/runtime domain。
- Browser Runtime 只消费 Runtime Definition + Execution Snapshot + check request。
- CSS edit 保留无 reload 热更新。
- HTML edit 能正确更新 preview。
- v1 IndexedDB progress 可以迁移并恢复。
- completed exercise 修改后仍保持 completed。
- Studio 能检查 Workspace 和 solution completeness。
- AGENTS.md 已反映 Front-end Lab Platform 的长期边界。
